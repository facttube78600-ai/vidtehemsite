    Publish checklist
    
              
    Title, embed URL and at least one category are required. A good SEO score (80+) needs a 30–60 character SEO title, a 120–160 character meta description and the focus keyword in the title, meta and slug.
    
            
    
          
    
        
    
      
    

      
      
    
        
    Site Meta
    
        
    This sets the meta tags for the whole live site (homepage title, description, keywords, social sharing). It is separate from the device-local Default Meta in the Meta Tags view. Saving here writes site-settings.json to GitHub — the public site picks it up on its next load.
    
        
    
          
          
          
          
          
          
          
          
    
          
    
          
          
          
          
          
          
    
          
    
        
    
      
    

      
      
    
        
    Ads
    
        
    One card per ad placement. OFF = the slot shows nothing. ON with code = the pasted code is shown. ON without code = the grey placeholder is shown. Paste your ad code (e.g. an AdSense unit) into the code box to turn an ad on.
    
        
    
        
        
    
      
    

      
      
    
        
    Header Code
    
        
    Always ON — this code is injected into the <head> of every page of the live site (Google Analytics, Search Console verification, etc.). It is NOT tied to the Ads on/off switches.

    Settings
    
        
    
          
    How publishing works
    
          
    Videos are stored in the site's video library. When you publish from this dashboard, your changes are saved and the public site picks them up automatically — new and updated videos appear without a redeploy.
    
          
    Live site: https://vidtehemsite.pages.dev/
    
        
    
        
    
          
    Security
    
          
    Your admin password is checked by the server every time you publish. It is never stored in the site code or anywhere in this dashboard — there are no password or token fields here.
    
        
    
        
    
          
    Data
    
          
    Quick Drafts and Default Meta are stored in this browser only. Everything else is stored with the site.
