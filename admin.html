    Settings
    
        
    
          
    How publishing works
    
          
    Videos are stored in videos.json in the GitHub repo facttube78600-ai/vidtehemsite (branch main). The dashboard saves through /api/publish, a Cloudflare Pages Function that commits the updated file to GitHub. The public site fetches the latest videos.json on every load, so published videos appear without a redeploy.
    
          
    Live site: https://vidtehemsite.pages.dev/
    
        
    
        
    
          
    Credentials
    
          
    ADMIN_PASSWORD and GITHUB_TOKEN live in Cloudflare Pages environment variables — never in code, never in this dashboard. The token is fine-grained, this repository only, with Contents: Read and write. There are no password or token fields anywhere in this dashboard.
    
        
    
        
    
          
    Data
    
          
    Quick Drafts and Default Meta are stored in this browser only. Everything else lives in GitHub.
